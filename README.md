## Интерфэйс

Утасны босоо дэлгэц дээр навигаци дээд хэсэгт байрлана. Өргөн дэлгэц дээр зүүн талын цэс байнга харагдана. Дөрвөн камерын цонх нарийн дэлгэцэд нэг багана, өргөн дэлгэцэд хоёр баганатай. RAINY тэмдэг нь нүүр болон Android аппын дүрсэнд харагдана.

## Суулгах

1. Android 7.0 буюу түүнээс дээш хувилбартай ARM төхөөрөмжид `rainy-reality-view-0.5.1-debug.apk` файлыг нээж суулгана. GitHub Actions-ийн амжилттай build-ийн `rainy-android` артефактад ижил хувилбар `rainy-debug.apk` нэрээр гарна.
2. **Камер** хэсэгт урд эсвэл арын камер сонгож, Android-ийн камерын зөвшөөрөл өгнө. Шууд USB UVC-д 64 битийн ARM болон USB Host порт шаардлагатай.
3. Шинэчлэхэд гарын үсгийн зөрүү гарвал өмнөх APK-г ямар түлхүүрээр бүтээснийг шалгана. Өөр түлхүүрээр гарын үсэг зурсан APK-г суулгахын өмнө хуучин аппыг устгах шаардлагатай байж болно. Устгахад аппын тохиргоо арилна.

Debug APK нь туршилтын түлхүүртэй. Release APK болон AAB-г түгээхийн өмнө эзэмшигчийн түлхүүрээр гарын үсэг зурна.

## Камер холбох

- **Камер → Утасны камер** хэсэгт эрх өгч, урд эсвэл арын камерыг сонгоно.
- **Камер → RTSP** хэсэгт `rtsp://192.168.1.20:554/live` хэлбэрийн хаяг оруулна. Хаягт хэрэглэгчийн нэр, нууц үг оруулах боломжгүй. Эхлээд камер, Android төхөөрөмж нэг сүлжээнд байгаа эсэх болон камерын RTSP профайлыг шалгана.
- **360° харагдац** хэсэгт камер бүрийн хаягийг тусад нь оруулна. Дөрвөн дүрс зэрэг ажиллахад төхөөрөмжийн декодер, камерын формат, сүлжээний чадал нөлөөлнө.
- **Нийцтэй байдал** хэсгээс USB видео төхөөрөмж танигдсан эсэхийг шалгана. **Камер → Android-д танигдсан гадаад камер** сонголт зөвхөн Android камерын системд харагдаж байгаа видео оролтыг нээнэ. Үйлдвэрийн камерын нийцэл нь загвар, үйлдвэрлэсэн он, видео интерфейс болон адаптерын бодит туршилтаар тогтоогдоно.

## AI загвар

Google MediaPipe EfficientDet-Lite0 INT8 загвар Gradle анхны build хийхдээ татаж, SHA-256 шалгаад APK-д багтаана. Суулгасны дараа AI загварыг ашиглахад интернэт шаардахгүй. `models.sha256` файл татаж авах загварын хүлээгдэж буй SHA-256 утгыг хадгална. Эх сурвалж нь [MediaPipe Object Detector загварын жагсаалт](https://ai.google.dev/edge/mediapipe/solutions/vision/object_detector). Загварын файл [Google-ийн түгээлтээс](https://storage.googleapis.com/mediapipe-models/object_detector/efficientdet_lite0/int8/1/efficientdet_lite0.tflite) авсан. Загвар солих интерфэйс болон GPU/NNAPI горим ороогүй.

Камерын native кадрыг дэлгэцийн чиглэлд эргүүлж, AI хүрээг кадрын өргөн ба өндрөөр [0, 1] мужид харьцуулна. Дэлгэц дээр кадрыг багтаах масштаб, хажуугийн сул зайг ашиглан хүрээг яг тэр кадр дээр зурна. 2D илрүүлэлтийн үр дүн нь камерын кадрын координаттай. Камерын мэдээллийн timestamp нь тухайн кадрт хадгалагдана.

## 3D замын дүрслэл

**Тохиргоо → Арын камерын тохируулга** хэсэгт камерын өндөр, хэвтээ шугамаас доош харсан өнцөг болон эргүүлж харуулж буй камерын кадрын хэвтээ, босоо харах өнцгийг хэмжиж оруулна. **Бодит орчны дүрслэл → 3D замын дүрслэл** товчийг асаахад бодит илрүүлэлтийн доод төв цэгээс гарсан туяаг хавтгай замтай огтлуулж, камерын баруун тийшх ба урагшх ойролцоо байрлалыг зурна. 2D дүрсийг хүссэн үедээ сонгоно.

Сценийн тор нь координатын лавлагаа. 3D горимд эгнээний тэмдэглэгээ, объектын бодит хэмжээ, хурд, замын налуу болон өндөрлөгийг хэмжих боломжгүй. Доод ирмэгээр тасарсан объект, тэнгэрийн хаяанд ойр туяа, 1–70 метрийн мужаас гарсан байрлалыг 3D-д оруулахгүй. AI таньсан замын тэмдэг, гэрлэн дохиог 2D дүрс дээр харуулна. Утас хөдлөх, эргэх, линз солигдох үед дахин тохируулна.

## Аюулгүй хэрэглээ ба нууцлал

Зогсоолд камерын тохиргоог хийнэ. Аппын дүрсэнд сохор бүс, хоцролт, алдсан эсвэл буруу илрүүлэлт гарч болно. Жолоодохдоо орчноо шууд харж, үйлдвэрийн толь болон камерын зааврыг дагана. Апп автомашины удирдлагатай холбогдохгүй.

AI нь төхөөрөмж дээр боловсруулна. Видео хадгалахгүй. Хурд харах зөвшөөрөл олгосон үед GPS хэмжилтийг зөвхөн тухайн дэлгэц дээр ашиглана. Байршил болон хурдыг сүлжээгээр дамжуулахгүй. RTSP нь хэрэглэгчийн оруулсан хаяг руу TCP холболт нээнэ. Хэл ба камерын тохиргоо аппын хувийн санах ойд хадгалагдана.

## Build ба түгээлт

JDK 17, Android SDK 35, Build Tools 35.0.0 шаардлагатай. Камерын навигацын UI тестийг төхөөрөмж эсвэл ARM эмулятор холбосны дараа `./gradlew :app:connectedDebugAndroidTest` ажиллуулж шалгана.

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease :app:bundleRelease
```

Signed release гаргахдаа `RAINY_STORE_FILE`, `RAINY_STORE_PASSWORD`, `RAINY_KEY_ALIAS`, `RAINY_KEY_PASSWORD` орчны хувьсагчийг CI secret эсвэл өөрийн компьютер дээр тохируулж `./gradlew :app:assembleRelease` ажиллуулна. Түлхүүр, нууц үгийг Git-д оруулахгүй. Google Play-д түгээх багцыг ижил signing тохиргоогоор `./gradlew :app:bundleRelease` ажиллуулж гаргана. Түгээлтийн хувилбар бүрд versionCode нэмнэ.

Үндсэн файлууд нь `MainActivity.kt` (дэлгэц, навигаци), `CameraViews.kt` (CameraX, RTSP), `Vision.kt` (загвар, хүрээ), `Sources.kt` (RTSP хаяг шалгах). AndroidX ба Media3 нь Apache 2.0 лицензтэй. MediaPipe эх код нь Apache 2.0 лицензтэй. EfficientDet-Lite0 INT8 загварын SHA-256 нь [Apache-2.0 нөхцөлтэй LiteRT Community түгээлт](https://huggingface.co/litert-community/MediaPipe-ObjectDetector-EfficientDet-Lite0/tree/main)-ийн файлтай таарсан. Apache-2.0 эхийг `third-party/Apache-2.0.txt`-д хавсаргасан. Аппын өөрийн түгээлтийн лицензийг эзэмшигч тогтооно.

### Камерын оношилгоо ба объект дагалт

**Нийцтэй байдал → Android камерын оролт шалгах** хэсэг Camera2-д харагдах камерын ID болон төрлийг харуулна. Жагсаалтад орсон камерын дүрс нээгдэх эсэхийг **Камер** хэсэгт тусад нь шалгана. USB төхөөрөмж танигдсан тухай мэдээлэл нь видео ажиллаж байгааг батлахгүй.

2D илрүүлэлт ижил ангиллын давхцаж буй хүрээг дараагийн кадарт ижил дугаартай харуулна. ID нь камерын сесс дотор хүчинтэй. Халхлалт, хурдан хөдөлгөөн болон объект солигдоход ID өөрчлөгдөж болно.

**Камер → RTSP → Сүлжээнээс RTSP камер хайх** нь нэг сүлжээнд `_rtsp._tcp` гэж өөрийгөө зарладаг үйлчилгээг харуулна. Сонгосон камерын хаяг, портыг бөглөж өгөх бөгөөд stream замыг хэрэглэгч оруулна. Бусад RTSP камерын хаягийг гараар оруулна.


### USB, үйлдвэрийн камер, 360° болон эгнээ

- **Камер → USB UVC** хэсэгт ARM64 төхөөрөмжийн USB Host портоор холбосон UVC камер сонгож, Android камерын болон USB төхөөрөмжийн зөвшөөрөл өгнө. Шууд USB дүрсэнд [Droid UVC 0.2.1](https://mikimn.github.io/droiduvc/) ашигладаг.
- **Камер → Android камерын оролт шалгах** хэсэг Android Camera2-д ил байгаа үйлдвэрийн болон бусад оролтыг ID-аар сонгоно. Зөвхөн үйлдвэрлэгчийн системд нээлттэй оролтод ажиллана. Үйлдвэрлэгчийн хамгаалсан системийн камерын хувьд албан ёсны OEM интеграц эсвэл тухайн камерын сигналд тохирсон видео адаптер шаардлагатай.
- **360° харагдац** хэсэгт урд, ард, зүүн, баруун RTSP дүрс холбоно. Дөрвөн камерт Газрын нэг хавтгай дээрх хол-зүүн, хол-баруун, ойр-баруун, ойр-зүүн цэгүүдийг тохируулж **Дээрээс нэгтгэх** сонгоно. Эдгээр дөрвөн трапец нь дэлгэц дээрх дөрвөн секторт бууна. Цэгүүд нь тухайн дэлгэцийн сессэд хадгалагдана. Дүрсүүд бие даан шинэчлэгддэг. Камерын хаяг солигдоход тухайн камерын калибрац арилна. Сүүлийн кадраас 1.5 секунд өнгөрсөн үед нэгтгэсэн дүрсийг түр нууж, дөрвөн эх үүсвэр дахин шинэчлэгдэхийг хүлээнэ.
- **Бодит орчны дүрслэл → 2D** нь тод, нарийн, төв рүү нийлж буй зурвасыг шар шугамаар тэмдэглэнэ. Шөнийн дүрс, нойтон зам, элэгдсэн тэмдэглэгээ, огцом эргэлт дээр баталгаажуулаагүй. Жолоодлогын шийдвэр гаргахад ашиглахгүй.
- **Android Auto** утасны проекцийн горимд энэ төрлийн камерын аппын дэмжигдсэн ангилал байхгүй. APK суулгадаг Android head unit дээр тусад нь туршина.

Droid UVC нь Apache 2.0 лицензтэй. Түүний native багц нь libuvc, libjpeg-turbo болон статик холбоостой LGPL libusb агуулдаг. Нийтийн түгээлтийн өмнө [эдгээр лицензийн нөхцөл](https://mikimn.github.io/droiduvc/#license)-ийг түгээх багцад тусгана.
